# VulnScanner

An advanced network security assessment tool designed to help identify potential security weaknesses in authorized systems and networks.

## Features

* 🔍 Port Scanning
* 🖥️ OS Detection
* ⚙️ Service & Version Enumeration
* 🛡️ Vulnerability Detection
* 📊 Security Risk Assessment
* 📝 Automated Vulnerability Reports
* 🔎 Network Information Gathering
* 📋 Detailed Scan Results

## Purpose

This project combines multiple security assessment techniques into a single tool to make basic network reconnaissance and vulnerability assessment easier and more organized.

It is intended for **educational purposes, cybersecurity labs, CTFs, and authorized security testing only**.

## Disclaimer

Only scan systems and networks that you own or have explicit permission to test. Unauthorized scanning or testing may be illegal.
